# מדריך — איך למלא את קובץ הרפרנס בנתונים אמיתיים

## הרעיון הבסיסי

כל תרגיל מיוצג ע"י מערך של `ReferenceFrame`. כל איבר במערך = **דגימה אחת = חצי שנייה** בסרטון התרגיל שביצעת (המאמן).

כלומר, אם תרגיל הסקוואט שלך נמשך 6 שניות עם 3 חזרות (2 שניות לחזרה), המערך יכיל **12 דגימות**:

```
אינדקס 0  -> t=0.0s
אינדקס 1  -> t=0.5s
אינדקס 2  -> t=1.0s
אינדקס 3  -> t=1.5s
אינדקס 4  -> t=2.0s  (סוף חזרה 1 / התחלת חזרה 2)
אינדקס 5  -> t=2.5s
...
אינדקס 11 -> t=5.5s  (סוף חזרה 3)
```

## מה זה t=0 (הנקודה ההתחלתית)

כפי שביקשת — **שתי השניות הראשונות הן עמידה ישרה**, לפני תחילת התרגיל בפועל. זו נקודת ה-0 (Baseline). ב-0.5Hz זה אומר 4 הדגימות הראשונות (t=0.0, 0.5, 1.0, 1.5) הן באותו מצב — עמידה ישרה, ערכים יציבים.

## איך לאסוף את הנתונים בפועל

1. לבשי את הנעליים החכמות
2. הפעילי את הבקר Master כשהוא רושם ל-Serial (כמו בקוד שכבר עובד אצלך)
3. תוך כדי שאת עומדת ישר 2 שניות ואז מבצעת את התרגיל 3 פעמים — תעדי בכתב/הקלטה את מה שמופיע ב-Serial כל חצי שנייה
4. כל שורה ב-Serial שמראה "ימין FSR: X | Y | Z" + "ימין תאוצה" + "ימין סיבוב" + אותו דבר לשמאל = דגימה אחת שצריך להכניס למערך

## מבנה כל דגימה בקוד

```cpp
{r_fsr0, r_fsr1, r_fsr2,  r_ax, r_ay, r_az,  r_gx, r_gy, r_gz,
 l_fsr0, l_fsr1, l_fsr2,  l_ax, l_ay, l_az,  l_gx, l_gy, l_gz}
```

- `r_` = נעל ימין (Master), `l_` = נעל שמאל (Slave)
- `fsr0` = GPIO0 = מסרק 5 (חיצוני)
- `fsr1` = GPIO1 = עקב
- `fsr2` = GPIO2 = מסרק 1 (פנימי)
- `ax,ay,az` = תאוצה בג'י (g)
- `gx,gy,gz` = סיבוב במעלות לשנייה

## דוגמה למילוי שורה אחת

נניח שב-Serial Monitor ראית בזמן t=1.0 שנייה (תחתית הסקוואט):

```
ימין FSR: 2800 | 3200 | 3100
ימין תאוצה: X=0.20 Y=-0.60 Z=0.80
ימין סיבוב: X=8.0 Y=3.0 Z=0.0
שמאל FSR: 2800 | 3200 | 3100
שמאל תאוצה: X=0.20 Y=-0.60 Z=0.80
שמאל סיבוב: X=8.0 Y=3.0 Z=0.0
```

זה הופך לשורה בקוד:

```cpp
{2800,3200,3100, 0.2,-0.6,0.8, 8.0,3.0,0.0,   2800,3200,3100, 0.2,-0.6,0.8, 8.0,3.0,0.0},
```

## איפה להוסיף בקוד

בקובץ `SmartStep_C6.ino`, חפשי את המערך המתאים לתרגיל (`mountainClimberReference`, `lungeReference`, או `situpReference`) והוסיפי/החליפי שורות בהתאם לנתונים האמיתיים שאספת. אין הגבלה על אורך המערך — תוסיפי כמה דגימות שצריך כדי לכסות את כל 3 החזרות בקצב של 0.5 שנייה לדגימה.

## בדיקה

אחרי שמילאת את המערך:
1. צרבי את הקוד המעודכן ל-C6
2. פתחי Serial Monitor
3. לחצי `m` (למטפסי הרים), `l` (ללאנג'), או `s` (לסיט אפ) כדי להתחיל "אימון" בדיקה
4. ה-C6 ידפיס ציון כל חצי שנייה לפי הנתונים החיים שהוא מקבל מה-Master

בעתיד, הטריגר `m`/`l`/`s` יוחלף בפקודה שמגיעה מהאפליקציה כשהמתאמן לוחץ "הפעל סרטון".
